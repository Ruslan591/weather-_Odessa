## Protocol

### Roles
- **CLAUDE** — основной разработчик: анализирует код, вносит изменения, запускает проверки.
- **GPT** — независимый архитектор и reviewer: проверяет алгоритм, diff, интеграцию и риски.
- **USER** — владелец проекта и финальный контролёр направления.

### Rules
1. Каждая запись начинается с роли, UTC-времени и TASK ID.
2. Не копировать большие файлы целиком.
3. Ссылаться на конкретные файлы, функции и commit SHA.
4. Перед изменением кода фиксировать Proposal.
5. После изменения фиксировать Changed / Tests / Risks.
6. При завершении задачи краткое решение переносится в постоянный контекст проекта.
