# Теневые позиции: пропущенные сигналы «ЗАХОДИТЬ» ведутся на бумаге (shadow_positions)

Запрос пользователя (2026-11-19, скрин поста ANIME SHORT «ЗАХОДИТЬ»): часть сигналов он пропускает по бытовым причинам. Нужно, чтобы такие ситуации «прокручивались» на бумаге с итогом и графиком, лучше как позиции с пометкой; итог сохраняется на странице (с пометкой); на счёт эти позиции не влияют; потом он смотрит ход сделок и на основе анализа обучает бота.

Связанные документы: telegram_bot.md (посты, вердикт, Автоордер), live_web.md (страница онлайн, порт 18111), vps_bridge.md (выкладка).

## Как работает
- Источник сигнала: пост слежения в экспрессе с мнением бота `call == "enter"` (отбой: tg_express.verdict, пробой: verdict_break). Условие: Автоордер ордер по этому посту не ставит (выключен, либо все слоты заняты). Вне экспресса вердикта нет, теневых позиций нет.
- tg_bot.send_watch после отправки поста вызывает `tg_shadow.record(w, V, Bk, mid, chat)`: запись в POS_DIR/shadow.json (вход, стоп, цель из плана вердикта, признаки, строки условий, снимки BTC 1m и режима, канал для графика, id поста). Одна открытая теневая позиция на пару и сторону (повторные «заходить» по той же паре не дублируются), не больше 30 открытых.
- Ведение: tg_bot.outbox_loop раз в минуту вызывает `tg_shadow.run()`: закрытые свечи 1m с Binance data-api, начиная с первой после поста. Стоп и цель из плана; обе в одной свече = стоп; гэп через стоп = выход по open свечи; таймаут 48 свечей таймфрейма сигнала (5m = 4 ч, не больше 72 ч) = выход по close.
- Комиссии как в pos.py: вход тейкер 0.05 % + проскальзывание 0.02 %; цель лимитом 0.02 %; стоп и таймаут 0.05 % + 0.02 %. R считается чистым (после комиссий) от расстояния до стопа.
- Нет сопровождения (БУ, частичное закрытие, трейлинг): это чистый тест сигнала «вход по рынку, стоп, цель». Правила сопровождения можно проверять отдельно по ходу цены.
- Если по слежению всё же появился реальный ордер (orders.json, src_watch = id слежения, в течение 30 мин после сигнала), запись получает статус taken и скрывается: реальная сделка уже на счёте.
- Что НЕ затрагивается: счёт, слоты, orders.json, positions.json, tg_corr (коррекции порогов), tg_review, tg_learn, reach_samples. Теневые позиции только читают свечи и пишут свои файлы.

## Файлы
- bot/positions/tg_shadow.py (в /opt/tg-notify, подключается try/except; удалить файл или shadow_cfg.json {"enabled": false} отключает).
- POS_DIR/shadow.json: {seq, items[]}, поля записи: id, sym, side, kind (bounce|break), tf, wid, mid, chat, t_sig, t_in, entry, stop, tp, risk, rr, f, status (open|closed|taken|void), exit, t_out, reason (target|stop|timeout), net_pct, r_mult, mfe, mae (в R), feat, rows, b1, rg, geo, ch.
- POS_DIR/shadow_paths.jsonl: по строке на закрытую позицию: id, sym, side, kind, tf, t_in, t_out, entry, risk, reason, r, step=300000, hlc = [[t, high_R, low_R, close_R], ...] по свечам 5m от входа до выхода (для проверки других правил выхода и для обучения).
- POS_DIR/shadow_cfg.json (необязательно): enabled, horizon (48), max_open (30), keep_closed (500), path (true).
- Закрытые хранятся до 500 штук (старые вытесняются), taken и void удаляются через 7 дней.

## Где смотреть
- Страница онлайн (18111 и 18110): раздел «👻 Теневые (пропущенные сигналы, на счёт не влияют)» между слежениями и архивом: сводка (открыто, закрыто, плюс/минус, итого R), строки с пометкой 👻 и номером, у открытых текущий R по живой цене, у закрытых итог (цель, стоп, таймаут) и R. Нажатие открывает график (свечи, вход, стоп, цель, выход, канал, H4 и D1 как у обычных). Теневые в архив закрытых и в его итог не попадают.
- Telegram: команда /shadow (сводка и последние 8). Сообщений при закрытии нет (чтобы не шуметь); при желании можно добавить тихое сообщение в канал «Разборы и обучение».

## Оговорки
- Вход по рынку по close сигнальной свечи (цена плана), реальная задержка пользователя не моделируется: это ответ на вопрос «что дал бы сигнал», а не «что получил бы я».
- Чистая проверка сигнала без сопровождения: результат может отличаться от реальных сделок, где стоп переносится вручную.
- Одинаковые сигналы по одной паре подряд считаются одной позицией, пока она открыта.
