## Технические детали

### Диагноз (04.10.2026, подтверждён на VPS)

Блоки `tomorrow`, `next3`, `marine` в собранном видео озвучены **старыми** mp3, хотя текст на кадре свежий.

Хронология прогона 04.10 (UTC):
- 10:35:56 `today` сгенерирован, 10:36:29 ранний push (`_git_push_block0_now`) → в git свежий, всё ок.
- ~10:37–10:39 генерируются `tomorrow`, `next3` — файлы лежат в рабочем дереве **не закоммиченными**.
- **10:40:01** — mtime `block_1_tomorrow*.mp3` и `block_2_next3*.mp3` одинаковый с точностью до 7 мс → это `checkout -B`/`reset --hard` из `sync_repo()` параллельного пайплайна (cron-такт :40). Файлы откатились к версии из HEAD (28.09).
- ~10:41 генерируется `marine`; **10:42:02** — снова одновременный mtime (такт :42, другой пайплайн) → откат к старому mp3.
- 10:42:10 `trend` пишется уже после откатов и сразу пушится → свежий.
- 10:42:45 пишется `blocks_meta.json` (тексты + `duration` считаются по свежим файлам на момент генерации) и пушится.
- 10:52:45 `make_video.py` рендерит видео: текст из свежего meta, звук `tomorrow/next3/marine` — из откатанных файлов.

Доказательства:
- `marine`: в meta `duration` 17.0 с, фактический mp3 в git 401517 байт ≈ 25.1 с (другой текст). `tomorrow`: 24.9 vs 25.2 с.
- Последний коммит `block_1_tomorrow.mp3` / `block_2_next3.mp3` — 28.09, `block_3_warnings`/`block_4_marine` — 02.10; никаких новых версий с тех пор, хотя meta обновляется каждый день.
- `today` и `trend` (ранний push / записан последним) — актуальны.

Это тот же механизм, что уже чинили для `block_0` (см. `docs/ai/`, `_git_push_block0_now`): ранний push покрывает только `today`/`tonight`, а все остальные блоки по-прежнему пишутся в общее дерево без лока, пока другие cron-пайплайны делают `sync_repo()`. Чем «посередине» блок, тем вероятнее откат.
