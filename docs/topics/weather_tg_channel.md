# Telegram-канал с погодой по Одессе (weather_tg_channel)

Запрос пользователя (2026-11-23): запустить канал в Telegram. Публиковать по сути всё, начать с прогноза и сводки по городу.

## Требования (от пользователя)
- Сводка по городу каждый час (опасение: не было бы спама).
- Главное: предупреждения о порывах ветра, об осадках, об аномалиях.
- Сводка по текущей погоде выводится только если наблюдается порыв ветра или осадки; указывать, в каком районе.
- Порог порывов: 8 м/с. Порог осадков: 0,1 мм/ч.
- Ложные срабатывания одного датчика фильтруем сразу (правило фильтра ещё уточнить, см. открытые пункты).
- Осадки: если идут только в одном районе, сообщаем сам факт и район; если по всему городу, указываем, где наиболее интенсивные.
- Сообщение при начале дождя и отдельное при его окончании.
- Если по прогнозу ожидаются осадки: предупреждение с временем до начала по прогнозу и сводка в реальном времени.
- Канал сначала частный (отладка), после отладки делаем публичным.
- Позже: карты и анимации (front_test, спутник), итоги верификации моделей, видео (Gemini).

## Технические детали (найдено в репо)
- Текущие наблюдения: data/pws_raw.json (hourKey, stationId, temp, pressure, wind, windGust, windDir, humidity, precip), обновляет pws_sync.yml.
- Группы станций: data/pws_groups.json (центр: IODESA138, IODESS44, IODESS16; север: IODESS37, IODESS41, IODESA137; остальные: IODESA139, IODESS31, IKRASN91).
- Готовая логика предупреждений по прогнозу: js/fc-alerts.js (weatherAlerts(hours)); можно портировать на Python для канала.
- Осадки рядом: data/nearby_precip.json; прогноз: data/forecast_days.json.
- Не путать с торговой темой: Telegram уже используется в проекте: docs/topics/telegram_bot.md (торговый бот, отдельная тема) и data/hmcbas_telegram_*.json (вода). Канал погоды ведём как отдельную тему.
